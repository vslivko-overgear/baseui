# Avatar Group

A row of overlapping avatars

## Usage

**Do**

- Use it to show a few people at once, with an overflow count for the rest

**Don't**

- Use it for more than a handful of people without the overflow

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | Avatars, optionally followed by one `AvatarGroupOverflow` |
| `size` | `'xsm' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| number` | `'md'` | Applied to every avatar |
| `shape` | `'circle' \| 'rounded' \| 'square'` | `'circle'` | Applied to every avatar |
