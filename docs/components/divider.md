# Divider

A line that separates content.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Line direction |
| `label` | `ReactNode` | — | Centered label (horizontal only) |
| `className` | `string` | — | Extra class name |
