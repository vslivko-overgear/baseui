# Slider

Selects a number in a range.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `number` | — | Value |
| `defaultValue` | `number` | `0` | Initial value |
| `onValueChange` | `(value: number) => void` | — | Called when the value changes |
| `min` | `number` | `0` | Minimum |
| `max` | `number` | `100` | Maximum. |
| `step` | `number` | `1` | Step. |
| `label` | `ReactNode` | — | Label above the track |
| `showValue` | `boolean` | `false` | Show the current value |
| `disabled` | `boolean` | `false` | Disabled state |
