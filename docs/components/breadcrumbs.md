# Breadcrumbs

Links that show where the user is in a hierarchy.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `items` | `Array<{ label: ReactNode; href?: string; onClick?: () => void }>` | — | Breadcrumb items in order |
| `label` | `string` | `'Breadcrumbs'` | Accessible name |
