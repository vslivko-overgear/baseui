# Section

A padded block with an optional maximum width

## Usage

**Do**

- Use it for a region of a page: a settings panel, a form group, a sidebar part
- Pair it with a heading and a Stack

**Don't**

- Use a Card when you mean a page region

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `padding` | `number` | `6` | Padding in gaps (1 gap = 4px), a step of the spacing scale: 6 is 24px |
| `maxWidth` | `number \| string` | — | Maximum width |
